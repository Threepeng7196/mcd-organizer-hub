两条真实可用的 MCP 工作流

全部基于麦当劳中国官方 MCP Server（35 个工具），工具名真实可查

🍱 团餐链路（beType=6 企业团餐）

query-nearby-stores→ query-meals 搭配→ query-meal-assistance 助餐→ query-promotions 满减→ calculate-price 核价→ 分账清单→ create-order（确认后）

🎉 派对链路（shopId=5）

mall-points-products 取商品→ query-party-city 城市→ query-party-store 门店→ query-party-store-date 日期→ query-party-store-session 场次→ party-order-create（确认后）

三步上手

接入你自己的麦当劳 MCP，马上能用

1

拿 Token

访问 open.mcd.cn/mcp，手机号登录后「控制台 → 激活」申请你的 Bearer Token。

2

接 WorkBuddy

在 WorkBuddy 连接器填入 mcp-config.example.json（把占位符换成你的 Token），启用并信任。

3

开口说需求

「12 人、预算 600、2 不吃辣，出团餐单」或「北京办派对看哪些门店能约」——AI 调用 MCP 完成。

本页为项目展示页。真正的团餐 / 派对功能需在 WorkBuddy 内接入你的麦当劳 MCP Token 后使用（Token 仅存于你本地，不会上传）。
